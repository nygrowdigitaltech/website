# Public assets

Drop these files here:

- `logo.png` — Nygrow rainbow logo (transparent background, square, ≥512×512)
- `og-image.png` — Open Graph image for social sharing (1200×630)
- `favicon.ico` — Browser tab icon
- `apple-touch-icon.png` — iOS home screen icon (180×180)

These are referenced in `app/layout.tsx` metadata.
